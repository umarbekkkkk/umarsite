# 🎮 Umarbek — Interactive RPG Character Sheet

Персональный сайт-визитка в стиле RPG-персонажа.
Многоязычный (RU/UZ/EN), с пасхалкой «Секретная комната».

## 📁 Структура

- `index.html` — разметка
- `style.css`  — стили (фиолетово-синяя неоновая тема)
- `script.js`  — логика, переводы, пасхалка
- `app.py`     — Flask-сервер (опционально)
- `requirements.txt`

## 🚀 Как запустить

### Вариант 1 — просто открыть (без Python)

1. Скачай все файлы в одну папку.
2. Открой `index.html` двойным кликом или через **Live Server** в VS Code.

### Вариант 2 — через Python (рекомендуется)

```bash
pip install -r requirements.txt
python app.py
